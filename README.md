# Sejin Chung — Personal Website

Personal academic website for Sejin Chung, an M.S. student at KAIST AI.

## Local preview

Open `index.html` in a browser. No build step or package installation is required.

## Content to add

- Profile photo: place the image in `assets/` and replace the placeholder in `index.html`.
- Email, LinkedIn, and CV links: replace the pending labels in the hero section.
- CV: place the PDF in `assets/` and link to it from `index.html`.

## Deployment

The site is designed to be published from the `main` branch using GitHub Pages.
